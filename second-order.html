Second-Order System Response

Investigate underdamped, critically damped, and overdamped responses by tuning ζ and ωn.

System Parameters

ζ — Damping Ratio 0.30
ωn — Natural Frequency (rad/s) 2.0

System Type

Underdamped (ζ < 1)
Underdamped — The system oscillates before settling. Common in lightly damped mechanical and electrical systems.

Parameters & Equations

The second-order model and its closed-form step response for each damping case.

Model

Transfer function G(s) = ωn² / (s² + 2ζωns + ωn²) ζ — damping ratio · ωn — natural frequency (rad/s).
Poles s1,2 = −ζωn ± ωn√(ζ² − 1) Underdamped → complex pair · critically damped → double real · overdamped → two real.

Step Response (unit step)

Underdamped (ζ < 1) ωd = ωn√(1 − ζ²)
y(t) = 1 − (e−ζωnt/√(1 − ζ²)) · sin(ωdt + φ) φ = atan2(ζ, √(1 − ζ²))
Critically damped (ζ = 1) y(t) = 1 − (1 + ωnt)·e−ωnt
Overdamped (ζ > 1) y(t) = 1 + (s1es2t − s2es1t)/(s2 − s1)

Performance Metrics

Closed-form indicators (ζ < 1) Overshoot = 100·e−πζ/√(1−ζ²) %
Peak time tp = π / ωd
Rise time tr ≈ (π − φ) / ωd
Settling (2%) ts ≈ 4 / (ζωn) Higher ζ → less overshoot but slower; higher ωn → faster.
