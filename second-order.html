Second-Order System Response

Investigate underdamped, critically damped, and overdamped responses by tuning ζ and ωn.

System Parameters

ζ — Damping Ratio 0.30
ωn — Natural Frequency (rad/s) 2.0

System Type

Underdamped (ζ < 1)
Underdamped — The system oscillates before settling. Common in lightly damped mechanical and electrical systems.

Presets

Transfer Function G(s) = ωn² / (s² + 2ζωn·s + ωn²)
Damped Frequency ωd = ωn√(1 − ζ²)
